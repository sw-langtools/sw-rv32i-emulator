Build the RV32I emulator after the sw-rv32i-isa crate provides a stable Instruction model, decode API, and register model. Work proceeds in small TDD steps: scaffold the crate to depend on sw-rv32i-isa and sw-isa-core, implement CpuState and Memory, implement fetch/decode/step/run, execute arithmetic and control-flow instructions, execute loads and stores, add dump helpers, add byte-loaded tests and examples, then add assembler-backed examples once sw-rv32i-asm exists.
